# nimbold

The source for [nimbold.github.io](https://nimbold.github.io), a GitHub Pages portfolio built with React, TypeScript, and Vite.

## Publish it free with GitHub Pages

1. Create a **public** GitHub repository named `nimbold.github.io` under the `nimbold` account.
2. Push this project to its `main` branch.
3. In the repository, open **Settings → Pages**, choose **GitHub Actions** as the source.
4. The included workflow builds and deploys the site to `https://nimbold.github.io/` on every push to `main`.

## Develop locally

```bash
npm install
npm run dev
```

The primary content lives in `src/App.tsx`; project information, contact details, experience, and writing placeholders are deliberately easy to replace there.
